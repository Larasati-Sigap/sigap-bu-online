# SETUP CEPAT SIGAP-BU ONLINE

1. Buat Supabase Project.
2. SQL Editor:
   - jalankan `supabase/schema.sql`
   - jalankan `supabase/seed_pegawai.sql`
3. Authentication > Add User.
4. Buat profile user di tabel `profiles`.
5. Upload source code ke GitHub.
6. Deploy ke Vercel.
7. Masukkan env VITE_SUPABASE_URL dan VITE_SUPABASE_ANON_KEY.
